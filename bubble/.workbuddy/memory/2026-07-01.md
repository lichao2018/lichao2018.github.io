# 2026-07-01 工作日志

## 泡泡龙游戏实现
- 创建了完整的泡泡龙 (Bubble Pop) HTML5 游戏：`E:\wackyfun\bubble\bubble-pop.html`
- 参考 Puzzle Bobble / Bubble Shooter 经典玩法设计

### 核心功能
- 六边形网格布局（奇偶行交错排列）
- 鼠标/触控瞄准 + 虚线弹道预览 + 墙壁反弹
- 碰撞检测 + 网格吸附定位
- 同色 3+ 连消（BFS 连通检测）
- 悬浮泡泡检测与掉落（BFS 从顶行检测）
- 天花板下压机制（每 N 次未消除触发）
- 死亡线判定

### 关卡系统
- 10 个手设关卡，递增难度（3→6 色，4→8 行，多种布局模式）
- 10 关后自动生成无尽关卡
- 布局模式：scattered / rows / triangle / diamond / ring / checkerboard / cross / vshape

### 效果
- 粒子特效（消除/掉落时）
- 屏幕震动
- Web Audio API 音效（射击/消除/掉落/过关）
- 深色星空主题背景
- 连击系统、分数、关卡进度显示
- 下压进度条
- roundRect polyfill 兼容

### 2026-07-01 10:45 修复：初始布局出现悬浮泡泡
- 问题：scattered 模式随机生成时，初始布局会出现未连到天花板的孤岛泡泡
- 修复：
  1. 在 `initGrid()` 之后调用 `removeInitialFloating()` 移除未连通的泡泡
  2. 若连通后泡泡不足 5 个，通过 `growConnectedCluster()` 从天花板向下 BFS 生成保证连通的簇
  3. 再次清理，确保开局所有泡泡都与天花板相连
- 同时启用了本地 HTTP 服务：`http://10.236.12.38:8080/bubble-pop.html`，可供手机局域网测试

### 2026-07-01 10:51 修复：UI 状态框穿帮
- 问题：顶部状态框半透明，能看到后面的泡泡；玩家误以为无法射击状态框后的泡泡
- 修复：
  1. 将 `.ui-box` 背景从 rgba(0,0,0,0.55) 提高到 0.85，并加阴影
  2. 将 `GRID_Y` 从 60 调到 100，让泡泡生成区域整体下移，避开状态框区域
### 2026-07-01 11:00 修复：泡泡被吸到错误位置
- 问题：碰撞检测只取距离，球被路过泡泡的侧面吸到其上方空位，无法飞到目标最后一排
- 修复：
  1. `updateFlyingBubble` 记录最近碰撞球并传给 `snapBubble(hitR, hitC)`
  2. `snapBubble` 优先在碰撞球的六边形相邻空位中搜索吸附位置
  3. 全局回退搜索加入 `DIAMETER*1.3` 距离限制，防止吸附到远处空位

### 2026-07-01 11:05 修复：球飞不到底部 / 球速调整
- 问题：用户期望射出去的球在空场时落到最底部，而不是粘在中途的网格上
- 修复：
  1. 新增 `dropSnappedBallToBottom()`，在泡泡碰撞到已有泡泡后沿六边形网格下落到最底部
  2. 碰顶情况（`hitR` 未定义）不下落，保持标准天花板吸附
  3. 将发射速度从 12 提高到 15，让球飞行更快

### 2026-07-01 11:17 修复：球碰到泡泡后仍下落到最底部
- 问题：用户反馈球“打到下面就停了”，射出的球在碰到已有泡泡后没有停在碰撞位置，而是沿六边形网格一路下滑到最底部（或最后一排有球的上方），行为像重力下落而非标准泡泡龙
- 修复：移除 `snapBubble()` 中调用 `dropSnappedBallToBottom()` 的下落逻辑，同时删除了未使用的 `dropSnappedBallToBottom()` 函数；现在球会直接粘在最近的空网格位上，符合标准泡泡龙体验
- 问题：屏幕上没有泡泡时，射出的球通过 dropSnappedBallToBottom 落到最后一排（row 15），正好在死亡线以下
- 修复：`dropSnappedBallToBottom` 根据 `bubbleCount` 判断屏幕是否有球；空屏时 maxRow = GRID_ROWS - 1，球只落到倒数第二排（row 14），有球时保持原行为落到 row 15

### 2026-07-01 11:59 碰撞效果可视化
- 用户要求：球停下时明显地显示碰撞位置
- 实现：
  1. 新增 `collisionEffects[]` 数组 — 冲击波扩散环效果（内环+外环，白色扩散渐隐）
  2. 新增 `highlightBubbles[]` 数组 — 被撞泡泡短暂白色光环高亮（shadowBlur 发光）
  3. `snapBubble()` 在 hitR/hitC 存在时：射出水泡自身颜色粒子(20个) + 被撞泡泡颜色粒子(12个) + 双冲击波环 + 被撞泡泡高亮
  4. `updateCollisionEffects()` 每帧更新环的半径和生命值
  5. `drawCollisionEffects()` 绘制冲击波环（lines，多圈渐隐）
  6. `drawGridBubbles()` 内绘制被撞泡泡高亮光环
  7. 关卡重置时清空 collisionEffects 和 highlightBubbles
