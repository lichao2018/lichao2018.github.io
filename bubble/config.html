这是给策划单独使用的配置页。这里改的是关卡 JSON 配置，不包含游戏画面。点“保存到当前浏览器”后，同域下的游戏页会立刻读到这份配置；如果要给 Android 包或正式服务器使用，仍然需要把导出的 JSON 覆盖到 game-config.json。
