泡泡龙配置台

这是给策划单独使用的配置页。配置来源是本地 JSON 文件，不依赖服务器接口。你可以导入本地文件、编辑后再保存回本地文件，游戏页支持直接读取这份本地配置。

配置页：独立发布 游戏页：只负责跑游戏 默认文件：game-config.json
打开游戏页
网页联调配置页编辑后下载 JSON，在游戏页点“读取本地配置”即可验证。
Android 发布把确认后的 JSON 文件放到包内并命名为 game-config.json。
回退随时点“读取默认 game-config.json”回到项目默认配置。
layout 编码0 表示空位；其他数字首位是颜色(1红/2绿/3蓝/4黄/5紫/6橙/7粉)，后续每位是一层障碍：1=冰冻、2=藤蔓、3=木箱。例：10红球、111红球双层冰、1123红球冰+藤+木箱。
levels[].name关卡显示名。
levels[].colors该关可出现颜色数，建议 3~7。
levels[].layout二维数组手动铺盘，配置后优先生效。示例：[[10,11,12,13,111,1123,0],[20,21,22,23,20,0,0]]。
levels[].pattern随机布局类型（仅当未配置 layout 时生效）：scattered/rows/triangle/diamond/ring/checkerboard/cross/vshape。
levels[].rows初始生成行数，建议 3~10。
levels[].density散列密度，0~1；仅散列类布局影响明显。
levels[].dropRate几次未消除后下压一次，值越小越难。
levels[].targetScore过关奖励目标分。
levels[].iceChance冰壳球概率，建议 0~0.3。
levels[].vineChance藤蔓球概率，建议 0~0.3。
endless.*无尽模式增长参数：颜色/行数/密度/下压频率/分数及冰藤概率的基准与步进。
